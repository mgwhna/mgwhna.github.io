01. Latar Belakang & Tantangan

The Challenge

Kartu nama fisik tradisional sering kali berujung hilang atau terbuang, sementara halaman portofolio digital 2D biasa terkadang terasa kurang interaktif dalam membangun impresi pertama.

Tantangan utamanya adalah bagaimana menghadirkan pengalaman visual premium berupa kartu nama 3 dimensi yang bisa dirotasi penuh oleh pengguna, namun tetap **ringan dimuat** di perangkat mobile ber-bandwidth rendah.

Kendala Teknis

Merender elemen grafis 3D secara langsung di browser tanpa menyebabkan penurunan FPS (*Frames Per Second*) atau lag pada layar HP.

02. Solusi & Pendekatan Teknis

Core Solution
CSS 3D Transforms

Memanfaatkan akselerasi perangkat keras (*GPU acceleration*) bawaan browser via CSS matrix3d untuk performa render 60 FPS.

Mouse/Touch Tracking

Mengintegrasikan JavaScript dinamis untuk melacak koordinat kursor (atau usapan jari di layar HP) guna menciptakan efek bayangan parallax yang realistis.

Zero Extra Weight

Tanpa menggunakan library eksternal yang berat (.obj / .gltf), murni dibangun dengan optimasi kode HTML/CSS agar hemat kuota internet pengguna.

03. Fitur Interaktivitas Kartu

Interactive Specs
Dua Sisi Dinamis (Double-Sided)

Kartu dapat di-klik untuk berputar 180° (*flip animation*), menampilkan logo personal branding mewah di sisi depan dan tautan kontak media sosial interaktif di sisi belakang.

Dynamic Foil & Glossy Effect

Mengimplementasikan gradasi linear CSS bergaya *holographic foil overlay* yang bergerak mengikuti sudut kemiringan arah pandang pengguna, menciptakan kesan material premium.
