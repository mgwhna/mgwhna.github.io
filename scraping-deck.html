01. Masalah Operasional

Tantangan Analisis Pasar

Pemantauan harga kompetitor dan tren komoditas di platform e-commerce jika dilakukan secara manual membutuhkan waktu hingga berjam-jam setiap harinya.

Selain lambat, data yang disalin secara manual rentan terhadap kesalahan ketik (*human error*), serta struktur halaman web yang sering berubah dapat menyebabkan hilangnya momentum keputusan bisnis yang krusial.

Blokade Sistem

Adanya proteksi IP blocking, Captcha, dan pemuatan konten berbasis JavaScript (Dynamic DOM) yang menyulitkan pengumpulan data teratur.

04. Strategi Konten Dinamis

Overcoming Hurdles

BeautifulSoup vs Selenium

Untuk web statis, skrip menggunakan metode **BeautifulSoup** demi performa kecepatan maksimal. Namun pada platform e-commerce modern dengan proteksi ketat, skrip beralih memanfaatkan **Headless Selenium/Playwright** untuk mensimulasikan gerakan klik dan scroll manusia secara nyata.

  • Implementasi Explicit Waits untuk menjamin komponen termuat sempurna sebelum diekstrak.
  • Rotasi proxy terintegrasi otomatis.
Wait Logic Implementation
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

element = WebDriverWait(driver, 10).until(
    EC.presence_of_element_color((By.CLASS_NAME, "product-price"))
)

05. Pembersihan Data Menggunakan Pandas

Regex & Formatting

Data mentah dari hasil scraping biasanya kotor (mengandung simbol mata uang, teks tambahan, atau spasi berlebih). Skrip secara otomatis menanganinya melalui pipeline pembersihan:

Kondisi Data Mentah (Raw HTML) Metode Regex / Pembersihan Hasil Bersih (Structured Output)
"Rp 150.000,-" .replace('Rp','').replace('.','') 150000 (Integer)
" Terjual 1,2rb+ pcs " Ekstraksi angka & perkalian pengali ribuan 1200 (Integer)
"Bawang Besar [STOK READY] " .str.strip() & pembersihan tag kurung "Bawang Besar" (String)
