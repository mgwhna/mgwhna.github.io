01. Masalah Kualitas Data

The Dilemma

Lebih dari 80% waktu analis data habis hanya untuk membersihkan data yang kotor, duplikat, hancur, atau memiliki format tidak konsisten sebelum pemodelan dimulai.

Pemrosesan data secara manual menggunakan spreadsheet rentan menyebabkan hang/crash jika ukuran data melebihi ratusan ribu baris, serta tidak dapat dijalankan secara berkala untuk kebutuhan data real-time bisnis.

Dampak Data Kotor

Menyebabkan hasil visualisasi dashboard salah arah dan membuat performa model machine learning menjadi bias (*Garbage in, Garbage out*).

03. Aturan Transformasi & Pembersihan

Data Wrangling

Logika pembersihan data terintegrasi otomatis di dalam pipeline:

Handling Missing Values

Menggunakan metode imputasi median untuk fitur numerik guna menghindari pencilan (outliers), dan imputasi modus atau penandaan khusus "Unknown" untuk fitur kategorikal.

De-duplication & Standardisation

Identifikasi otomatis data ganda berdasarkan ID unik transaksi, sinkronisasi format tanggal (YYYY-MM-DD), serta standardisasi penulisan string teks agar seragam.

04. Implementasi Skrip Python

Code Architecture

VLOOKUP & Merge Automation

Mengganti fungsi pencarian VLOOKUP tradisional yang lambat di Excel dengan metode penggabungan berkinerja tinggi **`pd.merge()`** di Python Pandas atau via Node Joiner di KNIME.

Metode ini mampu mencocokkan data antar tabel yang berbeda ukuran struktur dengan kecepatan pemrosesan super singkat tanpa memakan memory berlebih.

Pandas Cleaning Skrip
# Drop duplicates & merge data
df_clean = df.drop_duplicates(subset=['id'])
df_final = pd.merge(
    df_clean, ref_table, 
    on='customer_id', 
    how='left'
)
df_final['status'].fillna('Active', inplace=True)
